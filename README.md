# Devshri Metabolics — Royal Medical website

Responsive, static, single-page website concept. Open `index.html` locally in a browser, or deploy to any static host (Netlify, Vercel, GitHub Pages, conventional web hosting). No build step or framework required.

## Implemented
- Desktop, tablet and mobile layouts; collapsible mobile navigation
- Hero, clinic overview, services, doctor profiles, FAQs, clinic contact and map
- Direct tap-to-call and email links
- Booking links to the **existing Eka Care profile** linked from the current clinic website
- Responsive sections, keyboard focus states, metadata and semantic HTML
